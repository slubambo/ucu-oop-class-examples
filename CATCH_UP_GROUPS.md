# Stories for the five catch-up groups

Use the group number in the additional list supplied by the lecturer. The prefix **C** keeps these labels separate from the original class group numbers. Existing groups keep their existing stories.

| Catch-up label | Group in additional list | Members | Assigned story |

Each assigned folder contains complete starting code, expected output, a story explanation, eight foundation choices and a later-topic menu.

1. Run and understand the starting story.
2. A group of eight completes all eight foundation tasks, one per member. The group of seven chooses any seven, one per member.
3. Choose three different later-topic options as a group. Split their code and automated checks among all members.
4. Follow the same [fork, branch, PR and review workflow](GROUP_ASSIGNMENT.md) as the original groups.
5. Submit the combined work on the group fork's `main` branch by the end of **Wednesday, 21 October 2026, Uganda time**.

Your submission must include the full member list with access and registration numbers, your story title, contribution/review links and one group evaluation of no more than 250 words, as explained in [GROUP_ASSIGNMENT.md](GROUP_ASSIGNMENT.md).

The group list is used only to assign the five stories. The attendance PDF and full student roster are not part of this public repository.
