## Get started

To read and run the class examples, follow [Start here](START_HERE.md). For the assignment, first make or update the **group fork** and clone that fork, as described in [GROUP_ASSIGNMENT.md](GROUP_ASSIGNMENT.md).

Every story folder contains:

- `README.md`: the situation and a plain-English walkthrough.
- `story.py`: complete starting code with comments.
- `expected_output.txt`: output from the unchanged starting story.
- `EXTENSIONS.md`: foundation choices, one per member.
- `ADVANCED_EXTENSIONS.md`: later-topic choices, three per group.

The starting code uses Python's standard library and works offline. Your extensions can use standard-library tools such as `json` and `unittest`; no paid accounts, external API, GUI or database is required.

## How the ideas connect

A choice object knows its behaviour or requirement. A resource object owns the number and its rules. A coordinator brings them together and records success. Different choices answer the same method call, while each coordinator keeps its own state.

Read [OOP in plain English](OOP_IN_PLAIN_ENGLISH.md) for the Week 1–6 vocabulary. All names, events, prices, distances and resource amounts are fictional teaching examples.
